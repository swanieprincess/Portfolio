Color Palette

Micro-accents — minimal use: bullets, dashes & other tiny elements only

Typography & Elements

Subheading — Century Gothic / Poppins with soft sea-green glow

Body text is Poppins Light over pure black in light gray, airy and readable. Links look like this unvisited link in blue or this visited link in pink, and pull-quotes take the italic purple treatment:

“Content is King.” — Bill Gates
  • Unordered lists take a tiny magenta dot bullet — magenta otherwise appears only on visited links
  • Inline separators and dashes render in dodger blue
  • Nested items use a blue em-dash marker
    • Both accents stay at fleck scale — never fills, text, or buttons

Active / Hover State

Two-tone panel — hairline borders run purple on the top/left and aquamarine on the bottom/right, echoed by the dual neon box-glow on containers and dividers.

Signature Effects

  • Dual neon glow — box-shadow: 3px 3px 20px #663399, 5px 5px 20px #7FFFD4
  • Heading glow — text-shadow: 3px 3px 5px #663399, 3.5px 3.5px 5px #7FFFD4
  • Soft link glow — text-shadow: 2px 2px 2px #20B2AA
  • Micro-accents — magenta #FF00FF bullets · dodger blue #1E90FF dashes — tiny elements only
  • Circular imagery — border-radius: 50% on avatars and photos
  • Icon glow — black circle, aquamarine stroke, box-shadow: 0 0 14px #663399
  • Headers — Sacramento script, aquamarine
  • Body — Poppins 300 / Century Gothic, light gray
