CCU Design Theme

Theme Preview · Swan Moon Portfolio

Color Palette

Primary — electric blue & purple on a black canvas

Highlight accents — minimal use: bullets, dashes, links & other tiny elements only

Typography & Elements

Subheading — Century Gothic / Poppins with soft purple glow

Body text is Poppins Light over black in white, airy and readable. Links look like this unvisited link in blue or this visited link in hot pink (hovering turns either white), and pull-quotes take the italic purple treatment:

“Content is King.” — Bill Gates
  • Unordered lists take a tiny hot pink dot bullet — pink otherwise appears only on visited links
  • Inline dashes and separators · render in blue
  • Nested items use a blue em-dash marker
    • All accents stay at fleck scale — never fills, text, or buttons

Active / Hover State

Two-tone panel — hairline borders run purple on the top/left and blue on the bottom/right, echoed by the dual neon box-glow on containers and dividers.

Signature Effects

  • Dual neon glow — box-shadow: 1.5px 1.5px 20px #8705E4, 2.5px 2.5px 20px #11B4F5
  • Heading glow — text-shadow: 1.5px 1.5px 5px #8705E4, 1.75px 1.75px 5px #11B4F5
  • Title glow — text-shadow: 0 0 6px #8705E4 around the page title
  • Soft link glow — text-shadow: 0.5px 0.5px 2px #8705E4
  • Highlight accents — hot pink #FF06C1 bullets · blue #11B4F5 dashes & separators · white #FFFFFF hovers — tiny elements only
  • Accordion button — pill-shaped, border: 4px solid #D3D3D3 with box-shadow: 0 0 5px #8705E4
  • Circular imagery — border-radius: 50% on avatars and photos
  • Icon glow — black circle, blue stroke, box-shadow: 0 0 14px #8705E4
  • Headers — Sacramento script, blue
  • Body — Poppins 300 / Century Gothic, white
