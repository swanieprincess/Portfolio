# Portfolio — swanieprincess

Personal portfolio / digital resume site for Swan Moon (@SwaniePrincess).

## Design theme: Neon Swan

All design work on this repo (and any artifacts, decks, or pages produced for
SwAnIePrInCeSs) must follow the **Neon Swan** theme defined in
`theme/neon-swan.md`, with a live reference sheet in
`theme/neon-swan-preview.html` (fully self-contained — fonts embedded, safe to
open anywhere).

Quick reference:

- Background pure black `#000000`; body text light gray `#D3D3D3`
- Primary accents: aquamarine `#7FFFD4` and rebeccapurple `#663399`;
  light sea green `#20B2AA` for hovers and soft glows; twilight slate
  `#494762` for active/hover surface fills
- Micro-accents (tiny elements only — never fills, headings, or buttons):
  magenta `#FF00FF` for list bullets, tick dots, eyebrow-line middot
  separators, and visited links; dodger blue `#1E90FF` for dashes,
  eyebrow/subtitle text, and unvisited links
- Typography: Sacramento script for headings (aquamarine with layered
  purple + aquamarine glow), Poppins Light / Century Gothic for body
- Signature effects: dual neon box-shadow
  `3px 3px 20px #663399, 5px 5px 20px #7FFFD4`, two-tone hairline borders
  (purple top/left, aquamarine bottom/right), circular imagery
  (`border-radius: 50%`), italic rebeccapurple pull-quotes

## Repo layout

- `Digital Resume.html` — the site (single page, self-contained CSS/JS)
- `assets/` — SVG logo, favicon, and social icons styled to the theme
- `theme/` — Neon Swan theme spec and preview/reference sheet
