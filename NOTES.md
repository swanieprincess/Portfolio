## For Chelsea — bot branding repo idea

Proposal: create a separate design theme branding repo for the bots —
**WiserGuy**, **GateKeeper**, and **Bookie**.

The idea is to theme them all the same way the CCU theme works: one shared
base (neon glows on black, same typography, components, and effects), with a
**color variation for each bot** — its own accent palette, glow colors, and
badge. The themes are tokenized (CSS custom properties on `:root`), so each
bot variant is a one-block color swap on the shared base.

Each bot would get:

- A color palette variant on the shared base theme
- A styled preview/reference page
- Brand guidelines to match

bot.
