Drop the original Clutch Stellaaa example images here, then run
`python3 tools/crop_banners.py` from `projects/stellarose/`:

- `logo.png` — the wolf logo
- `current-challenges.jpg` — the wide Current Challenges banner
- `leaderboard.jpg` — the podium Leaderboard banner
- `ongoing-challenges.jpg` — the trophy banner
- `upcoming-events.jpg` — the calendar banner
- `community.jpg` — the crowned orbs banner

PNG, JPG or WEBP all work. The script writes text-free crops to `assets/`.
